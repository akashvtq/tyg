# SEO Pages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a 3-level, admin-authored SEO content section (`/seo`, `/seo/{subcategory}`, `/seo/{subcategory}/{topic}`) with Word (.docx) import, structured data and a sitemap, as specified in `docs/superpowers/specs/2026-09-24-seo-pages-design.md`.

**Architecture:** One self-referencing `seo_pages` table holds all three levels. Each row stores its full `path`, so a URL resolves with one indexed lookup. The public side is a single route (`/{category}/{subcategory?}/{topic?}`, with `category` limited to `seo`) served by a frontend controller that uses three small pure-PHP services: table of contents, schema.org JSON-LD, and nav grouping. The admin side follows the existing Blog module's patterns: resource controller, Blade views, Summernote editor, spatie permissions. The Word import runs entirely in the admin's browser (mammoth.js plus a cleanup script); the server only receives HTML, which it purifies with a new `seo_content` profile.

**Tech Stack:** Laravel 10, PHP 8.2, MySQL 8 (WAMP), Pest 2, spatie/laravel-permission 6, mews/purifier 3, jQuery + Summernote (admin), mammoth.js 1.x, Vitest + jsdom (JS tests only).

### Differences from the spec (intentional)

| Spec says | Plan does | Why |
|---|---|---|
| `TableOfContents`, `SchemaBuilder` classes | `TableOfContentsService`, `SchemaBuilderService` (plus `NavGroupService` and `SeoPageImageService`) | `tests/Architecture/ArchTest.php` requires every class in `App\Services` to end in `Service` |
| `<title>` filled via `@yield('title')` | SEO pages set `$fullTitle`, and `_head.blade.php` prints it **without** the " - Build Saas Links" suffix | The client's title tags are written as complete titles (up to 92 characters); the suffix would push them further past Google's display limit. Other pages keep the suffix |
| Feature test: trailing slash returns 301 | Manual check with `curl` (Task 14) | The redirect lives in Apache's `.htaccess`; Laravel's test client never goes through Apache |
| TOC "no H2 gives no items" | An H3 that comes before the first H2 gets an `id` but isn't listed in the TOC | Keeps the TOC a clean H2 → H3 tree and matches the spec's test case |

- [ ] **Step 4: Create the model**

Create `app/Models/SeoPage.php`:

```php
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;
use Illuminate\Database\Eloquent\Relations\HasMany;
use Illuminate\Support\Collection;
use Illuminate\Support\Facades\Cache;
use Illuminate\Support\Str;

class SeoPage extends Model
{
    use HasFactory;

    public const MAX_DEPTH = 3;

    public const CLUSTERS = ['core', 'inner', 'outer'];

    public const TREE_CACHE_KEY = 'seo_pages_tree';

    /**
     * First URL segments a category slug may not use (existing routes).
     * Existing `pages` slugs are checked separately in SeoPageRequest.
     */
    public const RESERVED_CATEGORY_SLUGS = [
        'admin', 'api', 'blog', 'service', 'software', 'login', 'register', 'user',
        'details', 'locale-set', 'contact', 'programmatic-seo-services', 'assets', 'build',
    ];

    protected $fillable = [
        'parent_id', 'title', 'nav_label', 'nav_group', 'slug', 'excerpt', 'content', 'faq',
        'featured_image', 'featured_image_alt', 'author_id', 'meta_title', 'meta_description',
        'canonical_url', 'primary_keyword', 'cluster', 'show_toc', 'show_cta', 'sort_order', 'is_active',
    ];

    protected $casts = [
        'depth' => 'integer',
        'faq' => 'array',
        'show_toc' => 'boolean',
        'show_cta' => 'boolean',
        'is_active' => 'boolean',
        'sort_order' => 'integer',
        'published_at' => 'datetime',
    ];

    protected static function booted(): void
    {
        static::saving(function (SeoPage $page) {
            $page->slug = Str::slug($page->slug);

            $parent = $page->parent_id ? static::query()->findOrFail($page->parent_id) : null;
            $page->depth = $parent ? $parent->depth + 1 : 1;
            $page->path = $parent ? $parent->path.'/'.$page->slug : $page->slug;

            if ($page->is_active && $page->published_at === null) {
                $page->published_at = now();
            }
        });

        static::saved(function (SeoPage $page) {
            // Saving each child re-runs its `saving` hook, which rebuilds its path
            // from ours; grandchildren follow through the same `saved` hook.
            if ($page->wasChanged('path')) {
                $page->children()->get()->each->save();
            }

            static::clearTreeCache();
        });

        static::deleted(fn () => static::clearTreeCache());
    }

    public function parent(): BelongsTo
    {
        return $this->belongsTo(self::class, 'parent_id');
    }

    public function children(): HasMany
    {
        return $this->hasMany(self::class, 'parent_id')->orderBy('sort_order')->orderBy('title');
    }

    public function author(): BelongsTo
    {
        return $this->belongsTo(Admin::class, 'author_id');
    }

    public function scopeActive(Builder $query): Builder
    {
        return $query->where('is_active', true);
    }

    public function url(): string
    {
        return url($this->path);
    }

    /**
     * Ancestors ordered from the category down (empty for a category).
     */
    public function ancestors(): Collection
    {
        $ancestors = collect();
        $parent = $this->parent;

        while ($parent) {
            $ancestors->prepend($parent);
            $parent = $parent->parent;
        }

        return $ancestors;
    }

    public function isPubliclyVisible(): bool
    {
        return $this->is_active && $this->ancestors()->every(fn (SeoPage $ancestor) => $ancestor->is_active);
    }

    public function resolvedMetaTitle(): string
    {
        return $this->meta_title ?: $this->title;
    }

    public function resolvedMetaDescription(): string
    {
        if ($this->meta_description) {
            return $this->meta_description;
        }

        if ($this->excerpt) {
            return $this->excerpt;
        }

        $text = trim(preg_replace('/\s+/u', ' ', strip_tags((string) $this->content)));

        return rtrim(Str::limit($text, 160, ''));
    }

    public function resolvedCanonical(): string
    {
        return $this->canonical_url ?: $this->url();
    }

    public function hasFeaturedImageFile(): bool
    {
        return $this->featured_image !== null && is_file(base_path('assets/'.$this->featured_image));
    }

    /**
     * @return array{0: int, 1: int}|null Width and height, or null if the file is missing.
     */
    public function featuredImageSize(): ?array
    {
        if (! $this->hasFeaturedImageFile()) {
            return null;
        }

        $size = @getimagesize(base_path('assets/'.$this->featured_image));

        return $size ? [$size[0], $size[1]] : null;
    }

    /**
     * Every publicly visible page (active, with all ancestors active), cached.
     * Used for the sidebar and the sitemap.
     */
    public static function visibleTree(): Collection
    {
        return Cache::rememberForever(self::TREE_CACHE_KEY, function () {
            $active = static::active()
                ->orderBy('depth')->orderBy('sort_order')->orderBy('nav_label')
                ->get(['id', 'parent_id', 'depth', 'title', 'nav_label', 'nav_group', 'slug', 'path', 'sort_order', 'updated_at'])
                ->keyBy('id');

            return $active->filter(function (SeoPage $page) use ($active) {
                $parentId = $page->parent_id;

                while ($parentId !== null) {
                    if (! $active->has($parentId)) {
                        return false;
                    }
                    $parentId = $active[$parentId]->parent_id;
                }

                return true;
            })->values();
        });
    }

    public static function clearTreeCache(): void
    {
        Cache::forget(self::TREE_CACHE_KEY);
    }
}
```

```php
<?php

namespace App\Services\SeoPage;

use Illuminate\Support\Collection;

class NavGroupService
{
    /**
     * @param  Collection<int, object>  $pages  Objects with `nav_group` and `sort_order`.
     * @return list<array{group: string|null, pages: Collection}>
     */
    public function group(Collection $pages): array
    {
        $sorted = $pages->sortBy('sort_order')->values();

        $ungrouped = $sorted->filter(fn ($page) => blank($page->nav_group))->values();

        $grouped = $sorted
            ->reject(fn ($page) => blank($page->nav_group))
            ->groupBy('nav_group')
            ->sortBy(fn (Collection $items) => $items->min('sort_order'))
            ->map(fn (Collection $items, string $name) => ['group' => $name, 'pages' => $items->values()])
            ->values()
            ->all();

        if ($ungrouped->isEmpty()) {
            return $grouped;
        }

        return array_merge([['group' => null, 'pages' => $ungrouped]], $grouped);
    }
}
```

```php
<?php

namespace App\Services\SeoPage;

use DOMDocument;
use DOMXPath;
use Illuminate\Support\Str;

class TableOfContentsService
{
    /**
     * @return array{html: string, items: list<array{id: string, text: string, level: int, children: list<array>}>}
     */
    public function build(string $html): array
    {
        if (trim($html) === '') {
            return ['html' => $html, 'items' => []];
        }

        $dom = new DOMDocument;
        $previous = libxml_use_internal_errors(true);
        $dom->loadHTML('<?xml encoding="UTF-8"><div id="toc-root">'.$html.'</div>', LIBXML_HTML_NOIMPLIED | LIBXML_HTML_NODEFDTD);
        libxml_clear_errors();
        libxml_use_internal_errors($previous);

        $xpath = new DOMXPath($dom);
        $root = $xpath->query('//div[@id="toc-root"]')->item(0);

        $used = [];
        $items = [];
        $currentH2 = null;

        foreach ($xpath->query('.//h2 | .//h3', $root) as $heading) {
            $text = trim(preg_replace('/\s+/u', ' ', $heading->textContent));
            if ($text === '') {
                continue;
            }

            $id = $this->uniqueId(Str::slug($text) ?: 'section', $used);
            $heading->setAttribute('id', $id);

            $item = ['id' => $id, 'text' => $text, 'level' => (int) substr($heading->nodeName, 1), 'children' => []];

            if ($item['level'] === 2) {
                $items[] = $item;
                $currentH2 = array_key_last($items);
            } elseif ($currentH2 !== null) {
                $items[$currentH2]['children'][] = $item;
            }
        }

        $output = '';
        foreach ($root->childNodes as $child) {
            $output .= $dom->saveHTML($child);
        }

        return ['html' => $output, 'items' => $items];
    }

    private function uniqueId(string $base, array &$used): string
    {
        $id = $base;
        $suffix = 2;

        while (isset($used[$id])) {
            $id = $base.'-'.$suffix++;
        }

        $used[$id] = true;

        return $id;
    }
}
```

```php
<?php

namespace App\Services\SeoPage;

class SchemaBuilderService
{
    /**
     * @param  list<array{name: string, url: string}>  $crumbs
     */
    public function breadcrumbList(array $crumbs): array
    {
        $items = [];
        foreach (array_values($crumbs) as $index => $crumb) {
            $items[] = [
                '@type' => 'ListItem',
                'position' => $index + 1,
                'name' => $crumb['name'],
                'item' => $crumb['url'],
            ];
        }

        return [
            '@context' => 'https://schema.org',
            '@type' => 'BreadcrumbList',
            'itemListElement' => $items,
        ];
    }

    /**
     * @param  array{headline: string, description: string, url: string, image: ?string, datePublished: string,
     *               dateModified: string, authorName: ?string, publisherName: string, publisherLogo: string}  $article
     */
    public function article(array $article): array
    {
        $schema = [
            '@context' => 'https://schema.org',
            '@type' => 'Article',
            'headline' => $article['headline'],
            'description' => $article['description'],
            'mainEntityOfPage' => ['@type' => 'WebPage', '@id' => $article['url']],
            'datePublished' => $article['datePublished'],
            'dateModified' => $article['dateModified'],
            'publisher' => [
                '@type' => 'Organization',
                'name' => $article['publisherName'],
                'logo' => ['@type' => 'ImageObject', 'url' => $article['publisherLogo']],
            ],
        ];

        if (! empty($article['image'])) {
            $schema['image'] = [$article['image']];
        }

        if (! empty($article['authorName'])) {
            $schema['author'] = ['@type' => 'Person', 'name' => $article['authorName']];
        }

        return $schema;
    }

    /**
     * @param  list<array{question: string, answer: string}>  $faq
     */
    public function faqPage(array $faq): ?array
    {
        if ($faq === []) {
            return null;
        }

        return [
            '@context' => 'https://schema.org',
            '@type' => 'FAQPage',
            'mainEntity' => array_map(fn (array $item) => [
                '@type' => 'Question',
                'name' => $item['question'],
                'acceptedAnswer' => ['@type' => 'Answer', 'text' => $item['answer']],
            ], array_values($faq)),
        ];
    }
}
```

Create `app/Http/Controllers/Frontend/SeoPageController.php`:

```php
<?php

namespace App\Http\Controllers\Frontend;

use App\Http\Controllers\Controller;
use App\Models\SeoPage;
use App\Services\SeoPage\NavGroupService;
use App\Services\SeoPage\SchemaBuilderService;
use App\Services\SeoPage\TableOfContentsService;
use Illuminate\Http\Response;
use Illuminate\Support\Collection;
use Illuminate\Support\Facades\Cache;
use Illuminate\View\View;

class SeoPageController extends Controller
{
    public function __construct(
        private readonly TableOfContentsService $toc,
        private readonly SchemaBuilderService $schema,
        private readonly NavGroupService $nav,
    ) {
    }

    public function show(string $category, ?string $subcategory = null, ?string $topic = null): View
    {
        $path = implode('/', array_filter([$category, $subcategory, $topic]));

        $page = SeoPage::active()->with('author')->where('path', $path)->first();
        abort_unless($page && $page->isPubliclyVisible(), 404);

        $trail = $page->ancestors()->concat([$page])->values();
        $root = $trail->first();
        $branch = $page->depth === 1 ? null : $trail->get(1);
        $tree = SeoPage::visibleTree();

        $toc = Cache::rememberForever(
            "seo_page_toc_{$page->id}_{$page->updated_at->timestamp}",
            fn () => $this->toc->build($page->content)
        );

        $children = $page->depth < SeoPage::MAX_DEPTH ? $page->children()->active()->get() : collect();
        $canonical = $page->resolvedCanonical();
        $hasImage = $page->hasFeaturedImageFile();

        return view('frontend.seo-page.show', [
            'page' => $page,
            'trail' => $trail,
            'root' => $root,
            'branch' => $branch,
            'sidebarGroups' => $this->nav->group($tree->where('parent_id', $root->id)),
            'branchGroups' => $branch ? $this->nav->group($tree->where('parent_id', $branch->id)) : [],
            'childGroups' => $this->nav->group($children),
            'toc' => $toc,
            'showToc' => $page->show_toc && count($toc['items']) >= 2,
            'imageSize' => $page->featuredImageSize(),
            'schemas' => $this->schemas($page, $trail, $canonical, $hasImage),
            'fullTitle' => $page->resolvedMetaTitle(),
            'metaTitle' => $page->resolvedMetaTitle(),
            'metaDescription' => $page->resolvedMetaDescription(),
            'canonicalUrl' => $canonical,
            'metaImage' => $hasImage ? asset($page->featured_image) : null,
            'metaImageAlt' => $hasImage ? $page->featured_image_alt : null,
            'ogType' => 'article',
        ]);
    }

    public function sitemap(): Response
    {
        return response()
            ->view('frontend.seo-page.sitemap', ['pages' => SeoPage::visibleTree()])
            ->header('Content-Type', 'application/xml; charset=UTF-8');
    }

    private function schemas(SeoPage $page, Collection $trail, string $canonical, bool $hasImage): array
    {
        $crumbs = collect([['name' => __('Home'), 'url' => route('home')]])
            ->concat($trail->map(fn (SeoPage $crumb) => ['name' => $crumb->nav_label, 'url' => $crumb->url()]))
            ->all();

        $schemas = [
            $this->schema->breadcrumbList($crumbs),
            $this->schema->article([
                'headline' => $page->title,
                'description' => $page->resolvedMetaDescription(),
                'url' => $canonical,
                'image' => $hasImage ? asset($page->featured_image) : null,
                'datePublished' => ($page->published_at ?? $page->created_at)->toIso8601String(),
                'dateModified' => $page->updated_at->toIso8601String(),
                'authorName' => $page->author?->full_name,
                'publisherName' => (string) setting('site_title'),
                'publisherLogo' => asset(setting('site_logo')),
            ]),
        ];

        if ($faq = $this->schema->faqPage($page->faq ?? [])) {
            $schemas[] = $faq;
        }

        return $schemas;
    }
}
```

```php
<?php

namespace App\Services\SeoPage;

use Illuminate\Http\UploadedFile;
use Illuminate\Support\Facades\File;

class SeoPageImageService
{
    /** Relative to `assets/`, the same convention FileManageTrait uses. */
    public const DIRECTORY = 'general/images/seo-pages';

    /**
     * Saves the upload as `{slug}.{ext}` (or `{slug}-2.{ext}`, ...) and returns the path for `asset()`.
     */
    public function store(UploadedFile $file, string $slug): string
    {
        $extension = strtolower($file->getClientOriginalExtension() ?: $file->extension());
        $directory = base_path('assets/'.self::DIRECTORY);
        File::ensureDirectoryExists($directory);

        $name = "{$slug}.{$extension}";
        $suffix = 2;
        while (file_exists("{$directory}/{$name}")) {
            $name = "{$slug}-{$suffix}.{$extension}";
            $suffix++;
        }

        $file->move($directory, $name);

        return self::DIRECTORY.'/'.$name;
    }

    public function delete(?string $path): void
    {
        if ($path !== null && is_file(base_path('assets/'.$path))) {
            unlink(base_path('assets/'.$path));
        }
    }
}
```

```php
<?php

namespace App\Http\Requests;

use App\Models\Page;
use App\Models\SeoPage;
use Illuminate\Contracts\Validation\Validator;
use Illuminate\Foundation\Http\FormRequest;
use Illuminate\Support\Str;
use Illuminate\Validation\Rule;
use Mews\Purifier\Facades\Purifier;

class SeoPageRequest extends FormRequest
{
    public function authorize(): bool
    {
        // Access is enforced by the `permission:seo-page-manage` middleware on the controller.
        return true;
    }

    protected function prepareForValidation(): void
    {
        $faq = collect($this->input('faq', []))
            ->filter(fn ($item) => is_array($item) && (filled($item['question'] ?? null) || filled($item['answer'] ?? null)))
            ->values()
            ->all();

        $this->merge([
            'parent_id' => $this->input('parent_id') ?: null,
            'slug' => Str::slug((string) ($this->input('slug') ?: $this->input('nav_label'))),
            'nav_group' => $this->input('nav_group') ?: null,
            'cluster' => $this->input('cluster') ?: null,
            'faq' => $faq,
            'show_toc' => $this->boolean('show_toc'),
            'show_cta' => $this->boolean('show_cta'),
            'is_active' => $this->boolean('is_active'),
            'sort_order' => (int) $this->input('sort_order', 0),
        ]);
    }

    public function rules(): array
    {
        $page = $this->currentPage();
        $parentId = $this->input('parent_id');

        $slugRules = [
            'required', 'string', 'max:60',
            Rule::unique('seo_pages', 'slug')
                ->where(fn ($query) => $parentId ? $query->where('parent_id', $parentId) : $query->whereNull('parent_id'))
                ->ignore($page?->id),
        ];

        if (! $parentId) {
            $slugRules[] = Rule::notIn(array_merge(SeoPage::RESERVED_CATEGORY_SLUGS, Page::pluck('slug')->all()));
        }

        return [
            'parent_id' => [
                'nullable', 'integer',
                Rule::exists('seo_pages', 'id')->where(fn ($query) => $query->where('depth', '<', SeoPage::MAX_DEPTH)),
            ],
            'title' => ['required', 'string', 'max:255'],
            'nav_label' => ['required', 'string', 'max:60'],
            'nav_group' => ['nullable', 'string', 'max:60'],
            'slug' => $slugRules,
            'excerpt' => ['nullable', 'string', 'max:1000'],
            'content' => ['required', 'string'],
            'faq' => ['array'],
            'faq.*.question' => ['required', 'string', 'max:500'],
            'faq.*.answer' => ['required', 'string', 'max:5000'],
            'featured_image' => [$page ? 'nullable' : 'required', 'image', 'mimes:jpeg,jpg,png,webp', 'max:2048'],
            'featured_image_alt' => ['required', 'string', 'max:125', 'not_regex:/\.(jpe?g|png|webp|gif|svg)$/i'],
            'author_id' => ['nullable', 'integer', 'exists:admins,id'],
            'meta_title' => ['nullable', 'string', 'max:255'],
            'meta_description' => ['nullable', 'string', 'max:170'],
            'canonical_url' => ['nullable', 'url', 'max:255'],
            'primary_keyword' => ['nullable', 'string', 'max:255'],
            'cluster' => ['nullable', Rule::in(SeoPage::CLUSTERS)],
            'show_toc' => ['boolean'],
            'show_cta' => ['boolean'],
            'is_active' => ['boolean'],
            'sort_order' => ['integer', 'min:0'],
        ];
    }

    public function messages(): array
    {
        return [
            'parent_id.exists' => __('Pages can only be nested three levels deep.'),
            'slug.not_in' => __('This slug is already used by another part of the site.'),
            'featured_image_alt.not_regex' => __('The alt text must describe the image, not be a file name.'),
            'faq.*.question.required' => __('Every FAQ answer needs a question.'),
            'faq.*.answer.required' => __('Every FAQ question needs an answer.'),
        ];
    }

    public function withValidator(Validator $validator): void
    {
        $validator->after(function (Validator $validator) {
            $page = $this->currentPage();
            if (! $page) {
                return;
            }

            // Depth is fixed: a page may only move to a parent at its current parent's level.
            $newParentDepth = $this->input('parent_id') ? (int) SeoPage::whereKey($this->input('parent_id'))->value('depth') : null;
            $currentParentDepth = $page->parent_id ? $page->depth - 1 : null;

            if ($newParentDepth !== $currentParentDepth) {
                $validator->errors()->add('parent_id', __('A page can only move to a parent at the same level as its current parent.'));
            }
        });
    }

    protected function failedValidation(Validator $validator): void
    {
        notifyEvs('error', $validator->errors()->first());

        parent::failedValidation($validator);
    }

    /**
     * Validated data ready to save: purified content and FAQ, without the uploaded file.
     */
    public function pageData(): array
    {
        $data = collect($this->validated())->except('featured_image')->all();

        $data['content'] = Purifier::clean($data['content'], 'seo_content');
        $data['faq'] = collect($data['faq'] ?? [])
            ->map(fn (array $item) => [
                'question' => trim(strip_tags($item['question'])),
                'answer' => Purifier::clean($item['answer'], 'seo_content'),
            ])
            ->values()
            ->all() ?: null;

        return $data;
    }

    private function currentPage(): ?SeoPage
    {
        $page = $this->route('seo_page');

        return $page instanceof SeoPage ? $page : null;
    }
}
```

```php
        ]);
    }

    public function create(Request $request): View
    {
        $page = new SeoPage([
            'parent_id' => $request->integer('parent_id') ?: null,
            'author_id' => auth('admin')->id(),
            'show_toc' => true,
            'show_cta' => true,
            'sort_order' => 0,
        ]);

        return view('backend.seo-page.create', $this->formData($page));
    }

    public function store(SeoPageRequest $request): RedirectResponse
    {
        $data = $request->pageData();
        $data['featured_image'] = $this->images->store($request->file('featured_image'), $data['slug']);
        $data['author_id'] ??= auth('admin')->id();

        SeoPage::create($data);
        notifyEvs('success', __('SEO page created successfully'));

        return redirect()->route('admin.seo-pages.index');
    }

    public function edit(SeoPage $seoPage): View
    {
        return view('backend.seo-page.edit', $this->formData($seoPage));
    }

    public function update(SeoPageRequest $request, SeoPage $seoPage): RedirectResponse
    {
        $data = $request->pageData();

        if ($request->hasFile('featured_image')) {
            $oldImage = $seoPage->featured_image;
            $data['featured_image'] = $this->images->store($request->file('featured_image'), $data['slug']);
            $this->images->delete($oldImage);
        }

        $seoPage->update($data);
        notifyEvs('success', __('SEO page updated successfully'));

        return redirect()->route('admin.seo-pages.index');
    }

    public function destroy(SeoPage $seoPage): JsonResponse
    {
        if ($seoPage->children()->exists()) {
            return response()->json([
                'status' => 'error',
                'message' => __('Delete or move this page\'s child pages first.'),
            ]);
        }

        $this->images->delete($seoPage->featured_image);
        $seoPage->delete();

        return response()->json(['status' => 'success', 'message' => __('SEO page deleted successfully')]);
    }

    /**
     * Pages in tree order: each category, then its subcategories, each followed by its topics.
     */
    private function treeOrder(Collection $pages, ?int $parentId = null): Collection
    {
        return $pages->where('parent_id', $parentId)
            ->flatMap(fn (SeoPage $page) => collect([$page])->concat($this->treeOrder($pages, $page->id)))
            ->values();
    }

    private function formData(SeoPage $page): array
    {
        if ($page->exists) {
            $parents = $page->depth === 1
                ? collect()
                : SeoPage::where('depth', $page->depth - 1)->orderBy('path')->get(['id', 'nav_label', 'path', 'depth']);
        } else {
            $parents = SeoPage::where('depth', '<', SeoPage::MAX_DEPTH)->orderBy('path')->get(['id', 'nav_label', 'path', 'depth']);
        }

        $groupsByParent = SeoPage::whereNotNull('nav_group')->get(['parent_id', 'nav_group'])
            ->groupBy(fn (SeoPage $p) => (string) ($p->parent_id ?? 'root'))
            ->map(fn (Collection $items) => $items->pluck('nav_group')->unique()->values());

        return [
            'page' => $page,
            'parents' => $parents,
            'admins' => Admin::orderBy('first_name')->get(['id', 'first_name', 'last_name']),
            'groupsByParent' => $groupsByParent,
            'hasChildren' => $page->exists && $page->children()->exists(),
            'clusters' => SeoPage::CLUSTERS,
        ];
    }
}
```

Create `assets/backend/js/seo-page-docx-clean.js`:

```js
/*
 * Cleans mammoth.js output from Google Docs / Word exports before it goes into the editor.
 * Rules: docs/superpowers/specs/2026-09-24-seo-pages-design.md §4.4.
 * Plain browser script: exposes window.cleanDocxHtml(html) -> { html, title, stats, warnings }.
 */
(function (root) {
    'use strict';

    function unwrap(el) {
        var parent = el.parentNode;
        while (el.firstChild) {
            parent.insertBefore(el.firstChild, el);
        }
        parent.removeChild(el);
    }

    function rename(el, tagName) {
        var replacement = el.ownerDocument.createElement(tagName);
        Array.prototype.forEach.call(el.attributes, function (attr) {
            replacement.setAttribute(attr.name, attr.value);
        });
        while (el.firstChild) {
            replacement.appendChild(el.firstChild);
        }
        el.parentNode.replaceChild(replacement, el);
        return replacement;
    }

    function isSafeHref(href) {
        var scheme = /^\s*([a-z][a-z0-9+.-]*):/i.exec(href);
        return !scheme || /^(https?|mailto)$/i.test(scheme[1]);
    }

    function all(rootEl, selector) {
        return Array.prototype.slice.call(rootEl.querySelectorAll(selector));
    }

    function cleanDocxHtml(html) {
        var doc = new DOMParser().parseFromString('<div id="docx-root">' + html + '</div>', 'text/html');
        var body = doc.getElementById('docx-root');
        var warnings = [];
        var title = null;

        // Rules 1 and 10: bookmark anchors go; unsafe links lose their href but keep their text.
        all(body, 'a').forEach(function (a) {
            var href = a.getAttribute('href');
            if (!href) {
                unwrap(a);
                return;
            }
            if (!isSafeHref(href)) {
                warnings.push('Removed an unsafe link: ' + href.slice(0, 40));
                unwrap(a);
                return;
            }
            Array.prototype.slice.call(a.attributes).forEach(function (attr) {
                if (attr.name !== 'href' && attr.name !== 'title') {
                    a.removeAttribute(attr.name);
                }
            });
        });

        // Rule 2: headings wrapped in a lone <strong>/<b>.
        all(body, 'h1, h2, h3, h4, h5, h6').forEach(function (heading) {
            var only = heading.children.length === 1 ? heading.firstElementChild : null;
            if (only && /^(STRONG|B)$/.test(only.tagName) && heading.textContent.trim() === only.textContent.trim()) {
                unwrap(only);
            }
        });

        // Rule 6: the first H1 is the title; any other H1 becomes an H2.
        var h1s = all(body, 'h1');
        if (h1s.length) {
            title = h1s[0].textContent.trim();
            h1s[0].parentNode.removeChild(h1s[0]);
            h1s.slice(1).forEach(function (h1) {
                rename(h1, 'h2');
            });
            if (h1s.length > 1) {
                warnings.push((h1s.length - 1) + ' extra Heading 1 converted to Heading 2 (a page has one H1: its title).');
            }
        }

        // Rules 3, 4 and 5: tables.
        all(body, 'table').forEach(function (table) {
            var rows = all(table, ':scope > thead > tr, :scope > tbody > tr, :scope > tr');
            if (!rows.length) {
                return;
            }
            var thead = doc.createElement('thead');
            var tbody = doc.createElement('tbody');

            rows.forEach(function (tr, rowIndex) {
                var cellTag = rowIndex === 0 ? 'th' : 'td';
                Array.prototype.slice.call(tr.children).forEach(function (cell) {
                    if (cell.tagName.toLowerCase() !== cellTag) {
                        cell = rename(cell, cellTag);
                    }
                    var paragraphs = Array.prototype.slice.call(cell.children).filter(function (child) {
                        return child.tagName === 'P';
                    });
                    if (paragraphs.length === 1 && cell.children.length === 1) {
                        unwrap(paragraphs[0]);
                    } else if (paragraphs.length > 1) {
                        paragraphs.forEach(function (p, index) {
                            if (index > 0) {
                                cell.insertBefore(doc.createElement('br'), p);
                            }
                            unwrap(p);
                        });
                    }
                });
                (rowIndex === 0 ? thead : tbody).appendChild(tr);
            });

            while (table.firstChild) {
                table.removeChild(table.firstChild);
            }
            table.appendChild(thead);
            if (tbody.children.length) {
                table.appendChild(tbody);
            }

            var wrapper = doc.createElement('div');
            wrapper.className = 'table-responsive';
            table.parentNode.insertBefore(wrapper, table);
            wrapper.appendChild(table);
        });

        // Rule 8: images are added by hand (with alt text), never imported.
        var images = all(body, 'img');
        images.forEach(function (img) {
            img.parentNode.removeChild(img);
        });
        if (images.length) {
            warnings.push('Removed ' + images.length + ' image' + (images.length === 1 ? '' : 's')
                + ' from the document. Add images with the editor\'s image button so they get alt text.');
        }

        // Rule 7: empty paragraphs.
        all(body, 'p').forEach(function (p) {
            if (p.textContent.trim() === '' && !p.querySelector('img, br')) {
                p.parentNode.removeChild(p);
            }
        });

        // Rule 9: skipped heading levels (warning only). The title counts as level 1.
        var previousLevel = 1;
        all(body, 'h2, h3, h4, h5, h6').forEach(function (heading) {
            var level = parseInt(heading.tagName.charAt(1), 10);
            if (level > previousLevel + 1) {
                warnings.push('Heading level skipped: H' + previousLevel + ' → H' + level
                    + ' ("' + heading.textContent.trim().slice(0, 50) + '").');
            }
            previousLevel = level;
        });

        return {
            html: body.innerHTML,
            title: title,
            stats: {
                h2: body.querySelectorAll('h2').length,
                h3: body.querySelectorAll('h3').length,
                tables: body.querySelectorAll('table').length,
                listItems: body.querySelectorAll('li').length
            },
            warnings: warnings
        };
    }

    root.cleanDocxHtml = cleanDocxHtml;
})(typeof window !== 'undefined' ? window : globalThis);
```

```js
$(function () {
    'use strict';

    var $input = $('#docx-import-input');
    if (!$input.length || typeof mammoth === 'undefined' || typeof window.cleanDocxHtml !== 'function') {
        return;
    }

    var MAX_BYTES = 10 * 1024 * 1024;
    var $report = $('#docx-import-report');
    var $content = $('#content');

    function escapeHtml(text) {
        return $('<span>').text(text).html();
    }

    $('#docx-import-button').on('click', function () {
        $input.val('');
        $input.trigger('click');
    });

    $input.on('change', function () {
        var file = this.files[0];
        if (!file) {
            return;
        }
        if (!/\.docx$/i.test(file.name)) {
            notifyEvs('error', 'Please choose a .docx file.');
            return;
        }
        if (file.size > MAX_BYTES) {
            notifyEvs('error', 'The file is larger than 10 MB.');
            return;
        }

        var existingText = $('<div>').html($content.summernote('code')).text().trim();
        if (existingText !== '' && !window.confirm('Replace the current content with the imported document?')) {
            return;
        }

        var reader = new FileReader();
        reader.onload = function (event) {
            mammoth.convertToHtml({ arrayBuffer: event.target.result })
                .then(function (converted) {
                    var result = window.cleanDocxHtml(converted.value);
                    var warnings = result.warnings.concat(converted.messages.map(function (m) {
                        return m.message;
                    }));

                    $content.summernote('code', result.html);

                    var titleNote = '';
                    var $title = $('#title');
                    if (result.title && $title.val().trim() === '') {
                        $title.val(result.title);
                        titleNote = ' Title set from the document\'s Heading 1.';
                    }

                    var stats = result.stats;
                    var html = '<div class="alert alert-info py-2 mb-2">Imported: ' + stats.h2 + ' H2, ' + stats.h3 + ' H3, '
                        + stats.tables + ' tables, ' + stats.listItems + ' list items.' + escapeHtml(titleNote) + '</div>';
                    if (warnings.length) {
                        html += '<div class="alert alert-warning py-2 mb-2"><ul class="mb-0">'
                            + warnings.map(function (w) { return '<li>' + escapeHtml(w) + '</li>'; }).join('')
                            + '</ul></div>';
                    }
                    $report.html(html);
                })
                .catch(function (error) {
                    notifyEvs('error', 'Could not read this document: ' + error.message);
                });
        };
        reader.readAsArrayBuffer(file);
    });
});
```
